# Progress

## Current stage

Harness domain discovery.

## Current objective

Model:

- Idea
- Requirement
- Decision
- Architecture Baseline

For each concept, understand:

- meaning;
- information content;
- lifecycle;
- invariants;
- relationships;
- authority;
- transition requirements.

## Working hypotheses

We currently believe:

- Idea represents an opportunity worth investigating.
- Requirement represents expected system behavior or constraint.
- Decision represents resolution of a meaningful question.
- Architecture Baseline represents an accepted version of system structure.

These are hypotheses and may change.

## Important discoveries so far

- Discussion may be an activity rather than a core entity.
- Draft is probably a lifecycle state rather than an entity.
- Lifecycle state and consistency/validity state may need to be separate.
- Changes to one artifact may invalidate downstream artifacts.

## Next

Refine the four core entities and identify missing concepts.

Then model relationships and workflows.
