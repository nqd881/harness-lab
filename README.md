# Harness Lab

This repository is a learning project for discovering, modeling, and
eventually implementing a software-development harness.

The harness is treated as a system that manages the lifecycle of
software development.

Current focus:

> Discover the harness domain before implementing the harness.

We are currently studying concepts such as:

- Idea
- Requirement
- Question
- Decision
- Architecture Baseline
- Evidence
- workflows
- transitions
- invariants
- traceability
- authority

Application implementation is intentionally out of scope for now.
